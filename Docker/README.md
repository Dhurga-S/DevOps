# California Housing Value Estimator

A FastAPI app that predicts the median house value for a California
census block group (the classic 1990 census dataset), served with a
single-page HTML frontend.

## Project layout

```
ca_housing_app/
├── app/
│   ├── main.py              FastAPI app (API + serves the frontend)
│   ├── static/
│   │   ├── style.css
│   │   └── script.js
│   └── templates/
│       └── index.html
├── model/
│   ├── housing.csv           training data (longitude, latitude, ... -> median_house_value)
│   ├── train_model.py        trains + saves the model
│   ├── ca_housing_model.joblib   (generated)
│   └── metrics.json          (generated)
├── requirements.txt
└── README.md
```

## Setup

```bash
cd ca_housing_app
python3 -m venv .venv && source .venv/bin/activate    # optional but recommended
pip install -r requirements.txt
```

## 1. Train the model (already done once, re-run any time)

```bash
cd model
python3 train_model.py
cd ..
```

This trains a `GradientBoostingRegressor` inside a `sklearn.Pipeline`
(median-imputation + scaling for numeric features, one-hot encoding for
`ocean_proximity`) and writes:

- `model/ca_housing_model.joblib` — the fitted pipeline
- `model/metrics.json` — holdout RMSE / MAE / R² and the known
  `ocean_proximity` categories, which the frontend reads to build the
  dropdown

Current holdout performance: **RMSE ≈ $53.8k, MAE ≈ $36.7k, R² ≈ 0.78**
on a 20% test split.

## 2. Run the API + frontend

```bash
uvicorn app.main:app --reload --port 8000
```

Then open **http://127.0.0.1:8000** in a browser.

## API

- `GET /api/health` — liveness check
- `GET /api/metrics` — model metrics + valid `ocean_proximity` categories
- `POST /api/predict` — body:

```json
{
  "longitude": -122.23,
  "latitude": 37.88,
  "housing_median_age": 41,
  "total_rooms": 880,
  "total_bedrooms": 129,
  "population": 322,
  "households": 126,
  "median_income": 8.3252,
  "ocean_proximity": "NEAR BAY"
}
```

`median_income` is in **tens of thousands of USD** (matches the original
dataset), so `8.3252` means $83,252.

Response:

```json
{ "predicted_price": 405647.16, "formatted_price": "$405,647" }
```

Interactive API docs are auto-generated by FastAPI at `/docs`.

## Notes

- Your original notebook (`California_price...ipynb`) was named for
  California housing but actually loaded the **Boston** housing dataset
  via `fetch_openml`. This app instead uses the real California housing
  dataset (longitude/latitude/rooms/income/ocean_proximity →
  median_house_value), fetched from the widely-used mirror in
  `ageron/handson-ml2` on GitHub, since `sklearn.datasets.fetch_california_housing()`
  downloads from a host that may be blocked in locked-down network
  environments.
- `median_house_value` in the source data is capped at $500,001 — the
  frontend's gauge uses that as its upper bound.
